# Patch-balanced V3 analysis

All variants use the same 278-clip development manifest. The selected V3 candidate classifies 246 clips correctly (88.49%), raises glass recall from 83.33% to 85.00%, and raises gunshot recall from 90.74% to 92.59% relative to the refined-Shatter baseline. Dog-bark recall falls from 78.33% to 75.00%; siren, speech, and thunderstorm recall remain unchanged.
