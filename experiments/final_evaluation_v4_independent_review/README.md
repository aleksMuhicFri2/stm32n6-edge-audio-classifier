# Slepi slušni pregled kandidatov za končni preskus

Pregled ocenjuje samo, ali posnetek jasno in v celoti vsebuje navedeni zvok ter ali je normalno slišen. Model, plošča in njune napovedi med pregledom niso uporabljeni. Nevihto z motečim visokofrekvenčnim ozadjem zavrnemo, namesto da bi jo posebej filtrirali. Po pregledu se deterministično izbere 70 sprejetih posnetkov.
