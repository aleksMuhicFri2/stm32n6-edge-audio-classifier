# Pregled tretje različice povečanja podatkov

Slepi pregled vsebuje 12 deterministično izbranih enosekundnih primerov
razbitja stekla. Zastopane so vse uporabljene družine sprememb. Sedem primerov
uporablja že preverjeni iskalnik razbitja, pri petih pa je varovalni pogoj
zamenjal sumljivo tih dogodek z najmočnejšim kratkotrajnim energijskim
vrhom. Med slednjimi je tudi izvor 92644, ki je v prvem pregledu vseboval le
hrup brez slišnega razbitja.

Spremembe so blažje kot v drugi različici: slabljenje je omejeno, dodani hrup
je tišji, hitrost se ne spreminja in močno stiskanje ni uporabljeno. Glasnost
ni normalizirana na vrh. Posnetki strelov so bitno enaki uspešni drugi
različici in jih zato ni treba ponovno poslušati.
